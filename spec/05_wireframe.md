# 05. 와이어프레임 & Storybook 카탈로그 — `@org/ai-react`

> **한 줄 요약**: 페이지가 아닌 **컴포넌트 단위 와이어프레임**. 각 컴포넌트의 default/loading/streaming/error/empty 상태를 ASCII로 정의하고, Storybook 카탈로그 구조를 함께 명시.

## 5. `<AiProvider>` (구성 시각화)

> 시각적 UI 없음. Storybook에서는 **트리 다이어그램 MDX**로 표현.

```
<AiProvider engine="openai" config={{...}}>
   │  Context: { adapter, storage, queryClient }
   ├── <AiChat />            ← useAiChat → adapter.stream(...)
   ├── <AiSummaryButton />   ← useAiSummary → adapter.chat(...)
   └── <YourCustomUI />      ← useAiChat()로 직접 구성
```

**Story**: 잘못된 구성 (apiKey만, proxyUrl 없음, dangerouslyAllowBrowser 미지정) → 콘솔 경고 + production-build에서 throw 시연.

## 6. 키보드 & 접근성 매트릭스

| 컴포넌트 | 단축키 | aria |
|---------|-------|------|
| AiChat composer | `Enter`=send, `Shift+Enter`=newline, `ESC`=cancel | textarea `aria-label`, send btn `aria-label` |
| AiChat list | `↑/↓`=스크롤(브라우저 기본) | `role="log"`, `aria-live="polite"`, `aria-atomic="false"` |
| AiSummaryButton popover | `ESC`=close, `Tab`=trap | `role="dialog"`, `aria-modal="true"` |
| Error banner | - | `role="alert"` |

## 7. Storybook MDX 가이드(섹션 헤더만 정의)

각 컴포넌트 MDX는 다음 섹션을 포함한다:
1. Quick start (5줄 import 예제)
2. Props (autogenerated table)
3. 상태별 스토리 데모 임베드
4. 헤드리스 커스터마이즈 (data-attribute 셀렉터 예시)
5. Tailwind preset 활용
6. 자주 묻는 질문 (CORS, SSR, persist key 충돌 등)
7. 관련 Hook 링크
